평가계획 제출 전 검사기 — 사용 안내

검사기 V2.2.0 · 학교 프로필 지원 · 설치 없음 · 파일은 브라우저 밖으로 전송되지 않습니다

1. 검사받는 선생님용 (1분)

  1. 담당 부장님이 안내한 검사기 링크를 엽니다.
  2. 화면 상단 「검사 프로필」에 우리 학교 이름이 보이는지 확인합니다.
    • 다른 학교 이름이 보이면: 담당자가 준 OO고_검사프로필.json 파일을 「프로필 불러오기」로 한 번만 등록하세요. 다음부터는 자동으로 기억됩니다.
  3. 완성한 평가계획서를 hwpx로 저장합니다. (한글 ▸ 파일 ▸ 다른 이름으로 저장 ▸ HWPX)
    • 구형 hwp 파일은 검사되지 않습니다.
  4. 파일을 검사기 화면에 끌어다 놓습니다. 여러 과목 동시 검사도 됩니다.
  5. 결과 읽는 법:
    • 수정 필요(빨강) — 규정 위반. 반드시 고쳐서 다시 검사하세요.
    • 확인 권장(노랑) — 의도한 것이면 그대로 둬도 됩니다. 근거를 준비하세요.
    • 검사 미완료(회색) — 통과가 아닙니다. 값을 읽지 못한 것이니 해당 표의 작성 상태를 확인하세요.
    • 각 항목의 「근거」에 어느 규정에 따른 판정인지 표시됩니다.

2. 학교 담당자용 — 우리 학교 프로필 만들기 (10분)

검사기는 학교마다 다른 기준(수행평가 하한, 기본점수 범위 등)을 프로필 파일로 읽습니다. 프로필이 없으면 해당 규칙은 검사에서 자동 제외되고, 전국 공통 규칙(반영비율 합계, 평가요소 형태, 표 간 교차검증 등)만 적용됩니다.

만들기

  1. 학교 프로필 생성기를 엽니다.
  2. ① 학교명과 학교급(고/중)을 입력합니다.
  3. ② 우리 학교 평가계획 양식(hwpx) 을 올립니다.
    • 양식 안의 유의사항 문구("수행평가 30% 이상", "기본점수는 만점의 20~40%" 등)를 자동으로 읽어 기준을 채웁니다.
    • 인식된 항목마다 근거 문장이 표시되니 원문과 맞는지 확인하세요.
  4. ③ 인식되지 않았거나 틀린 값은 표에서 직접 고칩니다.
    • 값을 비우면 그 규칙은 검사하지 않습니다.
    • 판정 강도: 규정 위반이면 FAIL, 권장 사항이면 REVIEW.
    • ③-2 지필평가 기간을 입력하면 정기시험 시기 대조 검사(X8)가 켜집니다. 학기가 바뀌면 프로필을 갱신·재배포하세요.
  5. ④ 「프로필 파일 저장」 → OO학교_검사프로필.json 이 내려받아집니다.

배포하기

검사기 링크 + 프로필 JSON 파일을 학교 메신저로 함께 안내합니다. 선생님들은 「프로필 불러오기」를 한 번 하면 브라우저가 기억합니다. 프로필을 갱신해 재배포한 경우(예: 새 학기 시험 일정), 선생님들도 새 파일을 한 번 다시 불러와야 적용됩니다.

알아둘 것

  • 성취기준 코드 대조는 전국 공통 교육과정 DB 기반이라 어느 고등학교든 작동합니다.
  • 정기시험 기간 대조(X8)는 프로필에 지필평가 기간을 입력한 경우에만 작동합니다. 입력이 없으면 해당 검사만 건너뜁니다.
  • 교육과정 편제표 대조(E1·F4)는 현재 원조 학교(복정고) 전용입니다. 다른 학교 프로필에서는 자동으로 「적용 안 함」 처리됩니다.
  • 중학교 프로필은 수치·형식 규칙 위주로 동작하며, 고교 전용 규칙(성취기준 DB 대조 등)은 자동 제외됩니다.
  • 프로필을 수정하면 새 JSON을 다시 배포하고, 선생님들도 새 파일을 한 번 다시 불러와야 합니다. 브라우저는 이전 프로필을 기억하고 있기 때문입니다.
  • 학교 기준(비율·기본점수 등)은 한 번 만들면 계속 쓰지만, 지필평가 기간은 학기마다 갱신해야 X8 검사가 올바르게 작동합니다.

3. 운영자용 — 저장소 구조

저장소 (GitHub Pages)
├── index.html              ← 검사기 (프로필 지원판)
├── profile_generator.html  ← 프로필 생성 도구
└── guide.html              ← 이 안내 문서
  • 검사기 규칙 업데이트 시 index.html 하나만 교체하면 모든 사용자에게 즉시 반영됩니다. 각 학교의 프로필 JSON은 건드릴 필요 없습니다.

자주 묻는 질문

Q. 파일이 외부로 전송되나요? 아니요. 평가계획 파일은 서버로 업로드되지 않고, 검사·프로필 생성 모두 브라우저 안에서만 처리됩니다. 페이지를 한 번 연 뒤에는 인터넷이 끊겨도 작동합니다.

Q. 프로필 없이 그냥 검사하면 안 되나요? 됩니다. 다만 학교별 수치 기준(수행 하한, 기본점수 범위 등)은 검사되지 않고 공통 규칙만 적용됩니다. 결과 화면의 「적용 안 함」 항목이 그 표시입니다.

Q. 우리 학교 양식을 올렸는데 아무것도 인식되지 않아요. 양식에 유의사항 문구가 없거나 표 구조상 문장이 조각나 있으면 인식되지 않을 수 있습니다. ③ 표에서 직접 입력하면 결과는 동일합니다.

Q. hwp 파일은 왜 안 되나요? 구형 hwp는 브라우저에서 읽을 수 없는 형식입니다. 한글에서 hwpx로 다른 이름 저장 후 사용하세요.
