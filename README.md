# 복정고 평가계획 제출 전 검사기

2학기 평가계획서(hwpx)를 제출하기 전에 스스로 점검하는 도구입니다.
**현재 버전: V1.9 (검사 규칙 37종)** — 버전은 검사 결과 화면의 「검사 규칙」 칸에서 확인할 수 있습니다.

## 🧑‍🏫 선생님 사용법 (3단계)

1. **hwpx로 저장**: 한글에서 평가계획서를 열고 [파일 ▸ 다른 이름으로 저장 ▸ HWPX] 형식으로 저장합니다. (hwp는 검사되지 않습니다)
2. **검사**: 검사기 페이지를 열고 hwpx 파일을 끌어다 놓습니다. 여러 과목을 한꺼번에 넣어도 됩니다.
3. **결과 확인 후 수정**:
   - 🔴 **수정 후 제출** — 필수 오류입니다. 반드시 고친 뒤 다시 검사하세요.
   - ⚪ **검사 미완료** — 값을 읽지 못한 항목이 있습니다. 표가 양식 그대로인지 확인하세요. *통과가 아닙니다.*
   - 🟡 **확인 후 제출** — 맞을 수도 있지만 한 번 봐 달라는 항목입니다. 의도한 것이면 그대로 제출해도 됩니다.
   - 🟢 **검사 통과** — 제출하시면 됩니다.

### 자주 나오는 안내

- **성취기준 검사 과목 선택**: 1·2학년(2022 개정) 문서는 결과 상단에서 과목이 자동 인식됩니다. 다르게 잡혔으면 드롭다운에서 바꿔 주세요 — 즉시 재검사됩니다.
- **「평가계획에 없는 성취기준 N개」**: 오류가 아니라 참고 자료입니다. 학기 편성상 의도한 범위라면 그대로 두세요.
- **성취도 체크박스**: '5. 기준 성취율과 성취도'에서 체크는 **정확히 2개**입니다 — 분할 방식 1개 + 그 방식 블록 안의 평정표 1개(과목 유형에 맞는 표).
- **개인정보 걱정 없음**: 이 검사기는 파일을 어디에도 전송하지 않습니다. 모든 검사는 선생님 컴퓨터의 브라우저 안에서만 실행됩니다.

### 문의
검사 결과가 이상하다고 생각되면(잘못 잡았거나, 잡아야 할 것을 놓쳤거나) 파일명·규칙 ID(예: N1, S2)와 함께 교육과정부로 알려 주세요.

## 🛠 관리자용 — 게시·갱신 가이드

### 최초 게시 (GitHub Pages, 약 5분)
1. github.com 로그인 → New repository → 이름 예: `bokjeong-checker` → **Public** → Create
2. [Add file ▸ Upload files] → 이 폴더의 `index.html`과 `README.md` 업로드 → Commit
3. [Settings ▸ Pages] → Branch: `main` / 폴더 `/ (root)` → Save
4. 1~2분 후 `https://<계정명>.github.io/bokjeong-checker/` 에서 접속 확인
5. **학교망에서 접속 테스트** 후 링크를 교사들에게 공유 (차단 시 대안: Netlify Drop)

### 버전 갱신
1. 새 검사기 HTML을 `index.html`로 이름 변경
2. 저장소에서 [Add file ▸ Upload files]로 덮어쓰기 → 커밋 메시지에 버전 기재 (예: `V1.10 — X6 추가`)
3. 교사는 링크 새로고침만 하면 됩니다 (재공유 불필요)

### 내장 데이터의 갱신 시점
| 데이터 | 갱신 필요 시점 |
|---|---|
| 2022 개정 성취기준 DB | 교육과정 개정·수정 고시 시 (연 단위) |
| 편제표 (E1·F4) | 매 학년도 편제 확정 시 |
| 학사일정 (X8) | 매 학기 지필평가 기간 확정 시 |
| 검사 규칙 | 시행지침·학교 규정 변경 시 |

갱신은 교육과정부 ↔ 개발 협업 채널(이슈로그 ID 방식)로 진행합니다.
